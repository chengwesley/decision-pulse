# Pulse Clock

放在桌面角落的小時鐘，瞄一眼就知道今天用 AI 工作的四大指標。

- 中央：現在時間、這段已經連續多久（或休息多久）
- 外圈四段弧，從右上順時針：① 決策密度 → ② 恢復窗口 → ③ 認知疲勞 → ④ 判斷品質
- 顏色：綠＝低、黃＝中、橘＝高、灰＝資料不足
- 時間每分鐘更新，四大指標每 30 分鐘重算一次
- 不跳通知、不發聲、不閃爍
- 文字語言跟 decision-pulse 的 `lang` 設定一樣（繁體中文／English）

## 需求

- Python 3.9 以上（只用內建的 tkinter，不用裝套件）
- 這個資料夾在 decision-pulse 裡面，裝好 decision-pulse 就有，不用另外安裝

數字全部來自同一個 skill 的 `scripts/scan_today.py --json`，小時鐘只負責顯示，不自己重算。

## 使用

雙擊 `pulse-clock.pyw`。

| 操作 | 作用 |
|---|---|
| 點一下 | 展開／收起小卡：四大指標數值、上次好好休息的時間、最該注意的一條提醒 |
| 拖曳 | 移動位置（會記住） |
| 右鍵 | 看完整儀表板、立即更新、保持在最上層、開機自動啟動、結束 |

「開機自動啟動」會在 Windows 的「啟動」資料夾放一個 `pulse-clock.vbs`，取消勾選就刪掉。

## 檔案

- `pulse-clock.pyw`：主程式
- `state.json`：自動產生，記住位置與設定

## 限制

- 主要在 Windows 測試。macOS 可以跑，但沒有圓形透明背景
- 「已連續 X 分」是上次更新時的數字，最多落後 30 分鐘
